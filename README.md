# Vyta website

One-page marketing site for Vyta. Plain HTML and CSS, no build step: open `index.html` in a browser.

- `index.html`: the page (hero, how it works, for owners, for firms, waitlist, footer)
- `styles.css`: styling, using the same navy / warm-grey palette and Georgia headings as the dashboard
